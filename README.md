# МаркетСклад

Учебное веб-приложение интернет-магазина с управлением складом.

## Технологии

- Ruby 3.4.11
- Ruby on Rails 8.1.4
- SQLite
- MVC
- REST API
- Git и GitHub

## Текущее состояние

Настроено окружение, создан проект и добавлена главная страница.
Спроектирована база данных. Остальные возможности разрабатываются поэтапно.

## Планируемые возможности

### Покупатель

- Просмотр каталога и карточек товаров.
- Поиск и фильтрация по категории и бренду.
- Регистрация и вход.
- Работа с корзиной и оформление заказа.
- Просмотр истории и статусов своих заказов.
- Отмена заказа до отправки.
- Отзывы о приобретённых товарах.

### Сотрудник

- Управление категориями, брендами и товарами.
- Управление складами и поставщиками.
- Создание и приёмка поставок.
- Просмотр остатков и резервов.
- Обработка заказов и изменение их статусов.

## Требования к реализации

- 12 связанных таблиц предметной области.
- Архитектура MVC.
- Изменение структуры базы через миграции Rails.
- REST API каталога и заказов с проверкой прав.
- Названия связанных записей вместо числовых кодов в интерфейсе.
- Проверка вводимых данных с понятными сообщениями об ошибках.
- Постепенная разработка с сохранением истории в GitHub.

## Запуск для разработки

Команды выполняются в Ubuntu через WSL из папки проекта:

    bundle install
    bin/rails db:prepare
    bin/rails server

Приложение доступно по адресу http://localhost:3000.
Для остановки сервера: Ctrl+C.
